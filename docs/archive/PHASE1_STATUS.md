## Design note

The pasted Phase 1 specification (GitHub webhook → LLM prompt builder → OpenCode worker → Discord/GitHub comment) supersedes the earlier planning docs in `docs/` (manual ChatGPT + Python `qa-runner`). Compatible parts of the old design were reused: compose layout and hardening, redaction rules, review-only kill switches, report structure. Docs that still describe the older design are marked "Planned" and will be revised once Phase 2 scope is approved.

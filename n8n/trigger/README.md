# PRQA 09 · Label-Triggered Pipeline (n8n-orchestrated)

`09-prqa-label-pipeline.json` is generated by `scripts/build/build_n8n_pipeline_workflow.py` — edit the generator, not the JSON.
It is kept apart from `n8n/workflows/` (the nine generated, inactive workflows) and is the only active workflow.

```
Every Minute ─► 1 Discover ─► Next Action ─► 2 Claim ─► 3 Env + Context ─► 3b Groq Prompt (model proxy) ─► 3c Quality Gate
                                 │                                                                     │
                                 ├─ recover (stale claim)                                     4 Grant + Submit OpenCode Job
                                 ├─ in progress / idle / prerequisites                                  │
                                                                                         Wait 30s ⟲ 5 Poll Job ─► 6 Report + Cleanup + Discord
                                                                                                        └─► Fail: Timed Out (cancel + Discord)
```

- Each stage is one `POST $PRQA_BRIDGE_URL/stage/<name>` → `prqa-n8n-bridge-relay` → `scripts/services/prqa_n8n_bridge.py` (Unix
  socket on the host) → `scripts/pipeline/prqa_stages.py <name>`. A blocked stage cleans up and reports to Discord itself.
- Groq: n8n sends the worker-rendered request to `prqa-model-proxy` with the inference-only `PRQA_MODEL_PROXY_PROMPT_TOKEN`;
  the proxy pins the model and enforces the shared budget. The worker validates + scores the output (85, hard fails);
  a failed, truncated or rejected generation falls back to the reference prompt, and the report records why.
- n8n holds no GitHub, provider, grant or Discord secret.

Import / activate:

```bash
python3 scripts/build/build_n8n_pipeline_workflow.py
docker cp n8n/trigger/09-prqa-label-pipeline.json prqa-n8n-1:/tmp/09.json && docker exec prqa-n8n-1 n8n import:workflow --input=/tmp/09.json
python3 scripts/setup/n8n_api.py activate PrqaLabelTrigger true
```

Bridge as a user service (survives logout of the session that started it):

```bash
mkdir -p ~/.config/systemd/user && cp deploy/systemd/prqa-n8n-bridge.service ~/.config/systemd/user/
systemctl --user daemon-reload && systemctl --user enable --now prqa-n8n-bridge
```
